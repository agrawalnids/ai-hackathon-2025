# MoodMate: AI-Powered 5-Minute Mood Uplift Break

## Introduction

Taking a short break during extended coding sessions helps you regain focus and avoid getting sidetracked. However, scrolling aimlessly on your phone can easily turn into an hour-long distraction, wasting valuable work time. Introducing **MoodMate**, a handy tool designed to provide you with a structured 5-minute break, guiding you towards a more productive and refreshing pause. **MoodMate** is a gentle AI companion designed to improve your emotional well-being during short breaks. Built using C# and Microsoft ASP.NET Core Blazor, MoodMate leverages advanced AI models and vector databases to deliver personalized curated content based on your mood and preferences, with the goal of fostering positivity and mental wellness.

## Description

Upon launching MoodMate, users are guided through a brief onboarding where they indicate their content preferences (likes/dislikes). *The preferences options are generated by our AI mental health expert.* This information is securely stored in a vector database, allowing the AI to tailor future experiences based on individual tastes and emotional states.

Once onboarded, users are shown a personalized feed of content items, such as quotes, videos, or tips, aligned with their current mood. Currently, the system allows mood selection from five options:

- Fantastic
- Happy (default)
- Neutral
- Meh
- Sad

### Time-Based Curation

MoodMate tailors the type of content not only by mood and preferences, but also by **time of day**:

- **Between 8:00 AM – 5:00 PM**: Content is geared toward productivity and focus to help users reset and return to work with clarity.
- **Outside these hours**: Content shifts toward relaxation and winding down, promoting mental calm and restfulness.

Every session runs for 5 minutes, with a countdown timer. Once time's up, users are gently reminded to return later for another break, reinforcing a healthy routine.

#### User Interaction Options
Changing the mood dynamically updates the content feed, ensuring relevance and emotional resonance. Users can further refine their experience by liking content, which is continuously learned by the system to improve subsequent sessions.

## Features

- AI mental health expert with 20+ years of simulated experience
- Personalized onboarding with preferences saved in a vector database
- Real-time mood-based content filtering with five emotional states
- Time-aware content (Productive by day, Relaxing by night)
- Dynamic content updates based on user mood and feedback
- Progressive learning to enhance user satisfaction over time
- 5-minute session timer for structured break time

## Technology Stack
- GPT-4o-mini as the chat model (hosted by GitHub Models Marketplace)
- Text-embedding-3-small as the embedding model (hosted by GitHub Models Marketplace)
- ChromaDB Client to interact with the local vector database
- Microsoft ASP.NET Core Blazor (C#) for interactive server-side rendering
- Compatible with Azure App Service or any .NET-compatible host
- Blazor Interactive Server Side rendering app, to be wrapped with Microsoft Teams Tab app wrapper for use in Microsoft Teams
